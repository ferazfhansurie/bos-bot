# 1.9.8

- Profile usage rings represent individual subscriptions, including multiple
  Claude accounts, with separate colors, quotas, and reset times.
- The profile menu names each account and the bots whose defaults use it,
  with a shortcut to account management.
- Subscription cards can hide a retired account from the profile while
  retaining its login and usage history.
- Automatic Claude quota fallback stays within the selected subscription;
  it cannot borrow another Claude account's quota.
- iPhone subscription cards show named account ownership and use stable
  account IDs even when display names match.
- iPhone new-thread actions show loading feedback immediately, hide the
  previous conversation and working state, and enable the composer only
  after creation completes. Navigation controls share subtle press motion
  and reusable haptics. Conversations, search, account usage and connected
  apps have loading skeletons; new motion respects Reduce Motion.

Add a second Claude login in Settings → Engines → Add Claude account, then
select that named account in each bot's model picker. Existing accounts and
bot assignments are preserved by the update.
